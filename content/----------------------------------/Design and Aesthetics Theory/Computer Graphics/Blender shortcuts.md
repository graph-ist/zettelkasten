[[Blender]] shortcuts reference and other reminders.
###### Remind

- After modifying an object, remember to apply all transformations (**Cmd + A → Apply All Transforms**) and correctly set the origin (**Right Click → Set Origin**).  
- If the model is not UV mapped, press **U → Unwrap** (only available in *Edit Mode*). Then assign a material, press **U → Smart UV Project** to automatically generate UVs.  
- In the *Image Editor*, switch the mode to **Paint** to draw in a 2D view.
