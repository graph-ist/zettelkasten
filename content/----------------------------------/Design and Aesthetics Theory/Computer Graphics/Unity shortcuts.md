[[Unity]] shortcuts reference and other reminders.
###### Scene View Navigation  

| Action          | Shortcut                                                             |
| --------------- | -------------------------------------------------------------------- |
| View            | Hold **Right Mouse Button** + drag                                   |
| Frame           | Press **F** in Scene view, or double-click a GameObject in Hierarchy |
| Orbit           | Hold **Alt** (macOS: Option) + **Left Mouse Button** drag            |
| Zoom            | **Scroll Wheel**, or Alt/Option + **Right Mouse Button** drag        |
| Flythrough Mode | Hold **Right Mouse Button** + use **WASD** (+ Q/E = Down/Up)         |
###### Scene View Tools 

| Action                        | Shortcut                                                |
| ----------------------------- | ------------------------------------------------------- |
| View                          | **Q**                                                   |
| Move                          | **W**                                                   |
| Rotate                        | **E**                                                   |
| Scale                         | **R**                                                   |
| Rect                          | **T**                                                   |
| Transform                     | **Y**                                                   |
| Frame (selected object)       | **F**                                                   |
| Orbit around                  | **Alt + Left Click + Drag**                             |
| Zoom                          | **Alt + Right Click + Drag**                            |
| Gizmos options                | **Right Click** on gizmos                               |
| Duplicate                     | **Cmd + D**                                             |
| Align camera to view          | **Cmd + Shift + F** (select object first)               |
| Snap function                 | Hold **V** with object selected                         |
| Change speed (Flythrough)     | Use **Scroll Wheel** while moving                       |
| Align view to camera position | **GameObject > Align View to Selected** (menu dropdown) |
