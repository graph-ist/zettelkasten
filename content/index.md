This is my research archive that integrates philosophy, cognitive science, and computer science through [[Luhmann]]'s [[Zettelkasten]] method. Notes function as interconnected epistemic units: each establishes explicit links with others, generating emergent conceptual structures without imposed hierarchy.

The system distinguishes *atomic notes* (discrete concepts) from *synthesis notes* (theoretical domains). The Graph View reveals thematic patterns through connection topology, transforming the archive into a networked thinking instrument.

Some of the notes were normalised using a large language model and may contain inaccuracies. Please note that these are intended to serve as preliminary study resources rather than exhaustive references.
